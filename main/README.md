# Research Lab Recruitment Portal

An automated web application for managing research lab recruitment from discovery to onboarding.

## Features

- **Homepage**: Showcase research areas and lab information
- **Positions Listing**: Display available positions with filters
- **Application System**: Multi-step form with auto-save
- **Applicant Dashboard**: Real-time status tracking
- **Professor Review**: AI-powered candidate screening and review
- **Onboarding Portal**: Guided onboarding with progress tracking

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Usage

Use the role switcher buttons in the navigation bar to view different user perspectives:
- **Student**: Browse positions, apply, track application
- **Professor**: Review applications, make decisions
- **Member**: View onboarding progress

## Technologies

- React 18
- Lucide React (icons)
- Tailwind CSS (utility classes)
- Modern ES6+ JavaScript
